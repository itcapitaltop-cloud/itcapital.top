## Анализ расхождений

### Текущая реализация

`AdminController::exportUserCard()` ([AdminController.php:232-363](app/Http/Controllers/AdminController.php#L232-L363)) формирует вертикальный список:

```
A                  B
Фамилия Имя        Иван Петров
Никнейм            ivan-petrov
...
Рефералы           Всего: 42
                                    <- пустая строка
    Имя реферала   Линия 1
        Имя        Линия 2
```

Без стилей, без шапки, без второго листа. Имя файла: `user-1212-card-20260911-131500.xlsx`.

### Эталон

Транспонированная раскладка, **один столбец на человека**:

| | A (подписи) | B (итоги) | C (владелец карточки) | D…DT (рефералы) |
|---|---|---|---|---|
| 1 | *(пусто, ht 61.5)* | | merge `C1:BK1` | |
| 2 | *(пусто, ht 79.5)* | | merge `C2:L2`, `R2:AT2`, `AY2:BI2`, `BJ2:BK2` | |
| 3 | Фамилия Имя | | Марина Бубнова | Rinat Zaripov … |
| 4 | Никнейм | | MarinaBy | Zrinat … |
| 5 | Номер линии | | 1 | 1 … |
| 6 | Реферал | | | |
| 7 | Город | | Северодвинск | Архангельск … |
| 8 | Телефон | | | |
| 9 | Социальные сети | | | |
| 10 | Пакеты Сумма | `=SUM(C10:DT10)` | 3000 | 0 … |
| 11 | Токены | `=SUM(C11:DT11)` | 0 | 0 … |
| 12 | Обучение онлайн | | | |
| 13 | Ранг | | 1 | 0 … |

Ключевые отличия, которые нужно устранить:

1. **Раскладка** — транспонированная, а не «подпись → значение».
2. **Рефералы** — не список снизу, а отдельные столбцы (`D`, `E`, …), номер линии в строке 5.
3. **Шапка** — две пустые высокие строки с заливкой и объединениями.
4. **Стили** — Arial, заливка по строкам, тонкие границы, центрирование.
5. **Итоги** — колонка `B` с формулами `SUM` по строкам «Пакеты Сумма» и «Токены».
6. **Закрепление** — заморозка столбца `A` (лист 1) и строки `1` (лист 2).
7. **Второй лист «задачи»** — таблица `Задачи` `A1:H45` с выпадающими списками и валидацией дат.
8. **Подписи** — `Реферал` вместо `Кто пригласил`, `Обучение онлайн` вместо `Обучение`.
9. **Имя файла** — `Фамилия Имя.xlsx`, а не `user-{id}-card-{timestamp}.xlsx`.

> **Примечание 2:** строки 1–2 листа «Главная» в эталоне **не содержат текста** — это оформительские полосы. Воспроизводим их как пустые объединённые блоки заданной высоты и заливки.
