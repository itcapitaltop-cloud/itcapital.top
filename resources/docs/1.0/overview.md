## Для чего нужна документация

Этот раздел описывает бизнес-функциональность проекта простым языком: как работает конкретный сценарий, какие есть правила, что видит пользователь или менеджер, и какие действия доступны в админке.

<a name="format"></a>
## Как читать страницы

Каждая страница описывает один функционал:

- назначение;
- пользовательский или админский сценарий;
- бизнес-правила;
- примеры расчетов;
- важные ограничения;
- технические файлы, где реализована логика.
