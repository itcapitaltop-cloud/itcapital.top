<a name="purpose"></a>
## Назначение

Ручной ранг позволяет администратору временно назначить пользователю ранг выше или равный его естественному рангу. Это нужно, когда менеджер вручную фиксирует стартовую позицию пользователя в партнерской программе.

При этом система продолжает считать естественный ранг по фактическим данным: личному депозиту и обороту по партнерским линиям.

<a name="terms"></a>
## Основные понятия

- Естественный ранг: ранг, который пользователь реально заработал по требованиям партнерской программы.
- Ручной ранг: ранг, который администратор назначил пользователю через админку.
- База ранга: минимальный оборот по линиям, который требуется для назначенного ручного ранга и считается полностью заполненным при ручном назначении.
- Фактический оборот линии: реальный оборот пользователя по линии, который добавляется в прогресс поверх заполненной базы ручного ранга.

<a name="enable"></a>
## Как работает включение ручного ранга

Когда администратор включает переключатель `Ранг установлен вручную`:

- пользователю записывается выбранный ранг;
- сохраняется дата включения ручного ранга;
- дальнейший прогресс к следующему рангу считается от минимальной базы назначенного ранга;
- требования рангов, которые пользователь проскочил за счет ручного назначения, считаются полностью заполненными;
- фактический оборот по каждой линии сохраняется полностью и добавляется в прогресс к следующему рангу поверх заполненной базы.

Ручной ранг не стирает реальные данные пользователя. Покупки пакетов, реинвесты и оборот структуры продолжают учитываться в естественном расчете.

<a name="progress"></a>
## Как считается прогресс по линиям

Для каждой линии система считает эффективный оборот так:

```text
эффективный оборот = минимальная база ручного ранга + фактический оборот линии за все время
```

Это означает:

- пройденные вручную ранги считаются заполненными;
- фактический оборот линии не обрезается до базы и не теряется;
- новый оборот после включения ручного ранга входит в общий фактический оборот и добавляется сверху;
- прогресс-бар показывает движение к следующему рангу, а не полный оборот за все время.

<a name="disable"></a>
## Что происходит при отключении

Когда администратор выключает `Ранг установлен вручную`:

- признак ручного ранга очищается;
- дата включения ручного ранга очищается;
- система запускает пересчет ранга без бонусов;
- пользователь возвращается к естественному рангу, рассчитанному по фактическим данным;
- доход и прогресс по линиям не должны обнуляться.

<a name="example"></a>
## Пример расчета

Администратор выставляет пользователю ранг 5.

Требования для ранга 5:

- линия 1: 4000;
- линия 2: 5000.

Фактический оборот пользователя до включения ручного ранга:

- линия 1: 6500;
- линия 2: 3000.

Расчет после включения ручного ранга:

- линия 1: система считает базу ручного ранга заполненной и добавляет фактические `6500`, прогресс-бар линии 1 начинается с 6500;
- линия 2: система считает базу ручного ранга заполненной и добавляет фактические `3000`, прогресс-бар линии 2 начинается с 3000.

Если после включения ручного ранга по линии 2 появляется новый оборот 1000, фактический оборот линии 2 становится 4000 и именно это значение участвует в прогрессе к следующему рангу.
